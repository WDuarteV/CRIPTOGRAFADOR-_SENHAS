🧩 Decomposição de Domínio (Chunking) & Sincronização entre Workers

Particionamento Disjunto [start, end) — Zero Condição de Corrida no Vetor

O espaço de 10.000.000 posições (320 MB) é dividido em fatias contíguas disjuntas: chunk = N / P, start = p × chunk, end = (p == P - 1) ? N : start + chunk. Cada trabalhador grava exclusivamente em sua fatia de memória (sem precisar de lock por índice) e acumula um checksum_local privativo, entrando na Região Crítica apenas 1 vez ao final para somar ao checksum_global.
